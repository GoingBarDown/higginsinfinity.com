DialPass: AI Phone-Tree Agent

Built a bidirectional audio engine with FastAPI WebSockets and asyncio that streams live Twilio call audio to OpenAI's Realtime API, letting an AI agent navigate phone trees and hand a live human to the user. Designed a two-tier inference state machine that classifies audio cheaply during hold and invokes the full real-time model only on menu prompts or agent pickup, reducing active AI inference by up to 90%.
