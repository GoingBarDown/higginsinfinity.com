# higginsinfinity.com

A fully responsive personal portfolio website built with plain HTML, CSS, and JavaScript, showcasing web design skills, personal projects, work experience, and contact details.

## Structure

- `index.html` — page markup
- `styles.css` — all styling (CSS custom properties for the color system, layout, and responsive rules)
- `main.js` — mobile nav toggle, scroll effects, and scroll-reveal animations
- `view_cv.html` — standalone CV/resume viewer
- `images/` — photo and favicon assets
